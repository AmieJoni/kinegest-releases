# KineGest — Releases

Ce dépôt **public** héberge uniquement les **installeurs** et la **fiche de version** de
l'application desktop KineGest (mises à jour automatiques).

- Dernière version : voir l'onglet **Releases** ci-contre, ou l'URL stable :
  `https://github.com/AmieJoni/kinegest-releases/releases/latest/download/version.json`
- Le code source, lui, reste dans un dépôt **privé**.

Chaque release contient :
- `Kinegest-Setup-<version>.exe` — l'installeur Windows (par utilisateur, sans droits admin)
- `version.json` — la fiche lue par l'application (version, notes, URL, empreinte SHA-256)
